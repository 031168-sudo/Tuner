# Мой Тюнер

Простой тюнер для шестиструнной гитары в стандартном строе E A D G B E. Без рекламы и без интернета, нужен только микрофон.

- Определение высоты тона алгоритмом YIN (`PitchDetector.java`), точность около 0,1 цента.
- Стрелка ±50 центов, подсказки «подтяни / ослабь», зелёная зона ±5 центов.
- Тап по струне фиксирует её, удержание проигрывает эталонный звук.
- Галочка ✓ появляется у струны, которая стабильно держится в строе.

## Сборка

Android SDK не нужен, хватит JDK, Python 3 и curl/git:

```
./build.sh          # → build/MoyTuner.apk
```

При первом запуске `fetch-tools.sh` скачает `android.jar` (API 29) и `dx`. Бинарный манифест и `resources.arsc` собираются скриптами в `tools/`. APK подписывается ключом `tuner.keystore`: если ключа нет, создаётся новый, а обновлять уже установленное приложение можно только тем же ключом.

## Иконка

Рисунок в `icon/*.svg` (фон и передний план адаптивной иконки), PNG-рендеры лежат там же.
